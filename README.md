# Strength Tracker

Веб - приложение для отслеживания прогресса в силовых тренировках. Позволяет пользователю записывать свои тренировки, отслеживать прогресс и анализировать результаты.

**Живая версия:** https://gym-tracker.dev

## Зачем этот проект

Я сам тренируюсь в зале и хотел следить за прогрессом — весом, объёмом, частотой подходов. Готовые приложения показались либо избыточными, либо неудобными под мой формат, поэтому решил сделать свой трекер.

## Стек

- **Backend:** Go, PostgreSQL, JWT-авторизация
- **Frontend:** vanilla JS, HTML, CSS (без фреймворков)
- **Инфраструктура:** Docker, Caddy, GitHub Actions (CI/CD)

## Технические решения

Vanilla JS выбран осознанно, на момент начала проекта только начинал изучать язык, и хотел разобраться в основах без фреймворка. Caddy я выбрал из-за того что это простое и лёгкое решение для проекта такого масштаба, не требующее сложной конфигурации как Nginx.


## Возможности

- Регистрация и авторизация с JWT-токенами
- Создание тренажёров с фото, ведение истории подходов по дням
- Кастомные SVG-графики прогресса (карта подходов, объём, частота тренировок)
- Настройки аккаунта: смена email/пароля/имени, удаление аккаунта
- Каскадное удаление данных, защита от IDOR, rate limiting

## Запуск локально

Понадобится Docker и Docker Compose.

1. Склонируйте репозиторий:
```bash
   git clone git@github.com:dimandrik/gym-tracker.git
   cd gym-tracker
```

2. Создайте `.env` в корне проекта:


```env
DATABASE_URL=postgres://gym_user:gym_pass@postgres:5432/gym_tracker
PORT=8080
JWT_SECRET=любая_случайная_строка
ALLOWED_ORIGINS=http://localhost:8081
DB_USER=gym_user
DB_PASSWORD=gym_pass
DB_NAME=gym_tracker
```

3. Запустите:
```bash
   docker compose up -d --build
```

4. Откройте фронтенд (`web/index.html`) через любой локальный сервер статики (например, встроенный в IDE).

Миграции применяются автоматически при старте сервера.

## Что было сложным / чему научился

- **SQL и работа с базой данных** — первая полноценная работа с PostgreSQL, написание SQL-запросов, миграции.
- **IDOR и безопасность** — больше узнал о защите от уязвимостей, связанных с доступом к чужим данным.
- **Визуализация данных через SVG** — это было абсолютно новой темой для меня. создание кастомных графиков прогресса с помощью SVG.
- **Деплой и CI/CD** — настройка автоматического деплоя через GitHub Actions, работа с Docker и Caddy.
